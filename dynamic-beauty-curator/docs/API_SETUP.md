# 외부 API 키 발급 가이드

백엔드 담당이 프로젝트 시작일(D+0, 5/13)에 바로 신청해야 한다.
API 키는 발급/승인에 시간이 걸리므로 미루면 일정 전체가 밀린다.

---

## 1. 기상청 자외선 관측 API

- 사이트: 기상청 API 허브 (apihub.kma.go.kr)
- 신청 API: 지상관측 > 자외선관측 > 자외선관측자료 조회 (`kma_sfctm_uv.php`)
- 활용 분야: 보건/의료 (또는 학술/연구)
- 활용 목적 예시:
  > 대학 팀 프로젝트로 정적 피부 타입과 실시간 환경 지표를 결합한 위치
  > 기반 스킨케어 큐레이션 API를 연구·개발합니다. 자외선 지수를 호출해
  > 피부 타입별 맞춤 케어 루틴을 도출하는 비상업적 프로토타입입니다.
- 발급 후: 인증키(authKey)를 `.env`의 `KMA_UV_API_KEY`에 입력

## 2. 에어코리아 (한국환경공단) — 3종 신청

공공데이터포털(data.go.kr)에서 신청. 대부분 자동승인.

| API명 | 용도 | 비고 |
|---|---|---|
| 대기오염정보 | 측정소별 실시간 PM10/PM2.5 농도 | 메인 데이터 |
| 측정소정보 | GPS 좌표 → 가까운 측정소 찾기 | 좌표 매핑 필수 |
| 미세먼지 경보 발령 현황 | 경보 발령 시 강조 메시지용 | 보조 |

- 활용목적 라디오: 연구(논문 등)
- 활용목적 텍스트 예시:
  > 대학 팀 프로젝트로 위치 기반 스킨케어 큐레이션 API를 연구·개발하며
  > 측정소별 실시간 PM10·PM2.5 농도를 호출합니다. 비상업적 프로토타입
  > 단계로 사용자 위치정보는 수집·저장하지 않습니다.
- 중요: 에어코리아는 인증키 1개로 모든 에어코리아 API 공용.
  → `.env`의 `AIRKOREA_API_KEY` 하나에 입력하면 됨

## 3. 카카오 좌표 변환 API (선택)

- 사이트: Kakao Developers (developers.kakao.com)
- 사용 API: 로컬 > 좌표로 행정구역정보 받기
- 무료, 즉시 발급
- 발급 후: REST API 키를 `.env`의 `KAKAO_API_KEY`에 입력

## 4. AI Hub 안면 피부 상태 이미지 데이터

- 사이트: AI Hub (aihub.or.kr)
- 자동승인 아님 — 검토 후 승인 (1~3일, 길면 일주일)
- 신청 목적: 인공지능기술 연구개발(R&D)
- 신청 사유 예시:
  > 대학 팀 프로젝트로 정적 피부 상태 데이터와 실시간 환경 지표를 결합한
  > 위치 기반 스킨케어 추천 알고리즘을 연구·개발합니다. 안면 피부 상태
  > 이미지의 라벨 체계를 분석해 환경 지표와 피부 트러블 간 매핑 룰북을
  > 도출하는 R&D 단계의 비상업적 프로토타입입니다.
- 데이터 용량이 크므로 처음엔 샘플만 받아 라벨 체계 파악

## 위치정보보호법 관련 (참고)

공공데이터 신청 화면에 "위치기반서비스사업신고필증" 안내가 뜨는데,
이는 상업적 LBS 사업자에게 적용되는 의무다.
학생/팀 프로젝트, 비상업적 프로토타입은 해당하지 않으므로
활용목적에 "비상업적 프로토타입", "사용자 위치는 수집·저장하지 않음"을
명시하면 된다. 반려되면 그때 보강 설명.

## .env 설정 최종 점검

모든 키를 받으면 `backend/.env.example`을 복사해 `backend/.env`로 만들고:

```
KMA_UV_API_KEY=발급받은_기상청_키
AIRKOREA_API_KEY=발급받은_에어코리아_키
KAKAO_API_KEY=발급받은_카카오_키
USE_FALLBACK=True
```

`.env`는 절대 깃에 올리지 말 것 (`.gitignore`에 이미 등록됨).
